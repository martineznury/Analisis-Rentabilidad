# Analisis-Rentabilidad
Proyecto de análisis de rentabilidad operativa global con SQL y Power BI
Este proyecto traduce datos crudos en métricas estratégicas de rentabilidad utilizando un modelo de datos en esquema de estrella.

Herramientas utilizadas:

Bases de Datos: SQLite, SQL (Limpieza y estructuración).

Visualización: Power BI Avanzado (Dashboards interactivos).

Estructura del Repositorio:

/Data: Datasets sin procesar.

/SQL: Consultas de extracción y transformación.

/Dashboard: Reporte visual interactivo con insights del negocio.
